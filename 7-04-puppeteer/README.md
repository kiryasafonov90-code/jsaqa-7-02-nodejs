# Домашнее задание 7.4 — Puppeteer 1

Решение двух задач Netology:
- индивидуальные тайм-ауты для каждого теста;
- отдельные хуки для групп тестов с разными стартовыми страницами.

## Установка

Требуется Node.js (рекомендуется LTS).

```bash
npm install
```

## Запуск тестов

```bash
npm test
```

## Что реализовано

### Задача 1. Puppeteer timeout
- Удалён глобальный `testTimeout` из `jest.config.js`.
- Для каждого из шести тестов явно указан тайм-аут 30 секунд.

### Задача 2. Puppeteer before and after hooks
- Для страницы GitHub Team используются собственные `beforeEach` и `afterEach`.
- Для трёх дополнительных страниц создан отдельный блок `describe` со своими хуками.
- Общие действия вынесены в функции `openPage`, `closePage` и `expectPageHeading`, чтобы не дублировать код.

Проверяемые дополнительные страницы: GitHub Features, Enterprise и Topics.
