# Домашнее задание 7.2 — Node.js

Решение задания Netology «Настройка VS Code для разработки. Конфигурирование дебагера для Node.js».

## Требования

- Node.js LTS и npm
- Visual Studio Code
- Расширения VS Code: GitLens, Prettier, ESLint, Beautify

## Установка и запуск

1. Установите актуальную LTS-версию Node.js с https://nodejs.org/.
2. Склонируйте репозиторий и перейдите в его каталог.
3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите пример:

   ```bash
   npm start
   ```

   В консоли должны появиться числа `30` и `50`.

## Проверка отладчика в VS Code

1. Откройте каталог проекта в VS Code.
2. Перейдите в **Run and Debug** и выберите конфигурацию **Debug current file**.
3. Запустите отладку клавишей F5.
4. Выполнение остановится на операторе `debugger;` в `index.js`. Проверьте значения `x` и `y` в панели Variables.
5. После продолжения выполнения в консоли появится результат `50`.

## Форматирование и ESLint

- Prettier настроен через `.prettierrc.json` и запускается при сохранении.
- ESLint проверяет `index.js`; команда проверки: `npm run lint`.
- Настройки VS Code находятся в `.vscode/settings.json`, конфигурация отладчика — в `.vscode/launch.json`.

## Скриншот отладки

Согласно заданию, сделайте собственный скриншот VS Code в момент остановки на `debugger;` и добавьте его в репозиторий, например в каталог `screenshots/`. Скриншот не включён автоматически, так как его нужно сделать в вашей среде VS Code.
